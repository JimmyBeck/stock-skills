# 字段口径标准

本文档定义每个字段的精确定义、计算公式、数据类型和边界条件。

## Sheet1 — 每日行情（16列）

### 列0: 日期
- **类型**: 采集
- **格式**: `YY.M.D`（如 `26.8.13`）或 `YYYY-MM-DD`（由配置 `date_format` 决定）
- **口径**: 证券交易所官方交易日历

### 列1: 收盘价
- **类型**: 采集
- **口径**: 当日收盘价（A股15:00收盘价）
- **信源**: 腾讯实时行情 `qt` 数组索引3 / K线行索引2

### 列2: 涨跌额
- **类型**: 计算
- **公式**: `收盘价 - 调整后前日收盘价`
- **除权除息日处理**: 前日收盘价需减去分红值（`prev_close - expected_div`）
- **信源**: 腾讯实时行情 `qt` 数组索引31（正常日）/ 自动调整（除权日）

### 列3: 涨跌%
- **类型**: 计算
- **公式**: `涨跌额 / 调整后前日收盘价 × 100`
- **精度**: 保留2位小数

### 列4: 板块参照涨跌%
- **类型**: 采集（需单独补填）
- **口径**: 所属行业板块当日涨跌幅%
- **信源**: 东方财富板块行情 API
- **注意**: 脚本写入时留空，由自动化任务中通过所在环境的网页抓取工具（WebFetch/FetchURL/curl 均可）补填

### 列5: 总市值（亿）
- **类型**: 采集
- **口径**: 当日总市值，单位亿元
- **信源**: 腾讯实时行情 `qt` 数组索引45
- **注意**: 港/美股可能无法自动获取

### 列6: 流通市值（亿）
- **类型**: 采集
- **口径**: 当日流通市值，单位亿元
- **信源**: 腾讯实时行情 `qt` 数组索引44

### 列7: 交易额（亿）
- **类型**: 计算
- **公式**: `成交额(元) / 100000000`
- **精度**: 保留2位小数
- **信源**: 腾讯实时行情 `qt` 数组索引35（格式: `万/亿/元`，取第3部分为元）

### 列8: 换手率%
- **类型**: 采集
- **信源**: 腾讯实时行情 `qt` 数组索引38
- **注意**: 港/美股无法自动获取

### 列9: 量比
- **类型**: 采集
- **信源**: 腾讯实时行情 `qt` 数组索引49
- **注意**: 港/美股无法自动获取

### 列10: 振幅%
- **类型**: 计算
- **公式**: `(最高价 - 最低价) / 调整后前日收盘价 × 100`
- **精度**: 保留2位小数
- **注意**: 以计算值为准；腾讯实时行情 `qt` 数组索引43的直采值仅作交叉参考，不直接写入

### 列11: 市盈率（TTM）
- **类型**: 采集
- **口径**: 收盘价 / 最近四季滚动EPS（TTM口径，由信源方计算提供）
- **信源**: 腾讯实时行情 `qt` 数组索引53（主）、东财实时 `f163`（×0.01 还原，备）
- **更新**: TTM 随每季财报滚动，无需手工维护 EPS
- **注意**: 实时源无历史值，历史不可回填；主备源财报更新时点可能不同，交叉验证阈值放宽至 ±0.2。2026-08-17 起从静态PE（close/EPS，见 registry pe_static 废弃条目）切换为本口径

### 列12-15: 交易记录
- **类型**: 人工填写
- **口径**: 用户个人交易记录，脚本留空

## Sheet2 — MACD三线（21列）

### MACD计算参数
- **输入价格**: 不复权收盘价（真实成交价，**平安证券口径**）
- **快线EMA**: 12日
- **慢线EMA**: 26日
- **信号线DEA**: 9日
- **MACD柱**: `2 × (DIFF - DEA)`（注意系数为2）
- **历史深度**: 月线 EMA 需全历史收敛。腾讯K线单次上限约2000条，采集端自动用搜狐历史前补（同样不复权）；已用平安证券锚点验证（中国海油/长江电力 2026-08-17 日/周/月逐位吻合）

### 日线MACD（列3-8）
- **DIFF**: EMA(12) - EMA(26)，基于日线收盘价序列
- **DEA**: EMA(DIFF, 9)
- **MACD柱**: 2 × (DIFF - DEA)
- **零轴标签**: DIFF > 0 = "零轴上方"，< 0 = "零轴下方"，= 0 = "零轴附近"
- **金叉死叉**: 前日DIFF≤DEA且今日DIFF>DEA = "金叉"；反之 = "死叉"；否则 = "无"
- **动能标签**: 今日MACD > 昨日MACD = "动能上升"；< = "动能下降"；= = "动能未变"

### 周线MACD（列9-14）
- **方法**: Provisional Close
  - 对每个交易日，序列 = [所有已完成周的收盘价] + [当日收盘价作为本周临时收盘价]
  - 已完成周: 该交易日之前的所有完整交易周，取每周最后交易日收盘价
  - 周划分: ISO周（周一至周五）
- **标签逻辑**: 与日线一致

### 月线MACD（列15-20）
- **方法**: Provisional Close（与周线同理）
  - 月度划分: 自然月（1日~月末）
  - 已完成月取月末最后交易日收盘价
- **标签逻辑**: 与日线一致

## 关键口径约定

### MACD柱系数
**MACD柱 = 2 × (DIFF - DEA)**，不是简单的 DIFF - DEA。
这一点已在长江电力项目中与Excel公式完全验证。

### Provisional Close 方法
周/月线MACD不等待周期结束才计算，而是用当日收盘价作为本周/月的临时收盘价。
这样每个交易日都能看到当前周期的MACD临时值，周末/月末后自动固化为最终值。

### 除权除息日处理
当检测到K线昨收与API昨收不一致时：
1. 判断是否为除权除息（差值 = 配置的 `expected_div`）
2. 若匹配：`调整后前收 = API昨收 - expected_div`，重算涨跌额/涨跌%/振幅
3. 若不匹配：标记为存疑，输出警告，需人工复核

### EMA收敛
MACD计算需要足够长的K线序列（建议≥1500条日线）。
月线EMA26需要约101个月度数据点（约5年）才能充分收敛。
脚本默认拉取2000条K线确保收敛。

### 历史K线使用前复权
K线接口 `web.ifzq.gtimg.cn/appstock/app/fqkline/get` 默认返回前复权数据，
确保MACD计算不受除权除息影响。

# 口径消歧方法论

## 核心原则

**带着调研结果问，不空手反问。**

"你说的北向资金是指A还是B？"不如"我查了东财和新浪，北向资金可采集的有这3种口径，分别是XXX，你要哪种？"

## 消歧流程

```
用户模糊描述
    ↓
[拆解] 列出所有可能的口径解释（基于领域知识）
    ↓
[调研] 每种解释在信源中的实际可得性
    ↓
[呈现] 把"可得的选项 + 各自含义 + 示例值"摆给用户
    ↓
[确认] 用户选定 → 锁定口径 → 写入 registry
```

## 常见歧义案例库

### 北向资金

| 可能意图 | 口径 | 信源可得性 |
|---------|------|-----------|
| 当日北向净流入额 | 亿元，收盘后更新 | 东财可采集 |
| 北向持股数量 | 股 | 东财可采集 |
| 北向持股占比 | 占总股本% 或 占流通股本%（又一个分歧点） | 东财可采集 |
| 5日累计净流入 | 计算字段 | 用日净流入累加 |
| 陆股通持股（≠北向，2024年后口径有变） | 历史口径断点问题 | 需特别注意 |

### 市值

| 可能意图 | 口径 |
|---------|------|
| 总市值 | 股价 × 总股本 |
| 流通市值 | 股价 × 流通股本 |
| A股市值 | 仅A股部分（含H股的公司不同） |

### 换手率

| 可能意图 | 口径 |
|---------|------|
| 基于流通股本 | 最常见，腾讯qt用此口径 |
| 基于总股本 | 部分源用此口径，数值差3倍 |

### PE（市盈率）

| 可能意图 | 口径 |
|---------|------|
| 静态PE | 收盘价 / 最近年报EPS（腾讯 qt[39]、东财 f164） |
| 动态PE | 收盘价 / 预测年化EPS（腾讯 qt[52]、东财 f162） |
| PE-TTM（滚动四季） | 收盘价 / 最近四季滚动EPS（腾讯 qt[53]、东财 f163；**本项目默认口径**） |

### 成交量

| 可能意图 | 口径 |
|---------|------|
| 成交量（手） | 1手 = 100股 |
| 成交量（股） | 原始股数 |
| 成交额（元） | 金额 |
| 成交额（亿） | 金额÷1亿 |

## 识别不存在的概念

用户可能描述的东西没有现成数据对应：

- "主力意志力指标" → 不是标准字段，引导转向主力净流入、大单占比
- "市场情绪温度计" → 不是标准字段，引导转向涨跌家数比、换手率中位数
- "机构共识评级" → 可能需要付费数据源，引导转向可采集的替代品

**不要硬造字段。** 如果概念不存在，明确告诉用户，并给出可采集的替代方案。

## 消歧后的产出

消歧完成后的 registry 条目必须包含（**注意：消歧阶段只填写下面这个子集用于确认口径，完整 21 字段条目结构见 registry_schema.md**）：

```json
{
  "field_id": "north_bound_holding_pct",
  "name": "北向资金持股比例",
  "definition": "北向资金持股数量 / 总股本 × 100",
  "unit": "%",
  "type": "采集",
  "disambiguation_notes": "用户最初说'北向资金'，经消歧确认为持股占比(占总股本)，非净流入额"
}
```

`disambiguation_notes` 记录消歧过程，便于未来回溯为什么这样定义。

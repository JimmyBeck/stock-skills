# 数据源清单

本文档记录每个字段的数据来源、接口格式、字段映射和备用方案。

## 主信源：腾讯行情

### 1. 日K线接口（主源）

- **URL**: `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,2000,`
- **编码**: UTF-8
- **返回格式**: JSON
- **数据范围**: 单次数上限约2000条日K线（不复权，真实成交价）；collector 会自动用搜狐历史前补更早K线以满足月线MACD收敛
- **更新频率**: 每交易日收盘后（约15:30后可用）
- **用途**: MACD计算（需长序列确保EMA收敛）+ 交易日历

**响应结构**:
```json
{
  "data": {
    "sh600900": {
      "qt": { "sh600900": [...实时行情数组...] },
      "day": [
        ["2020-01-02", "开", "收", "高", "低", "成交量", ...],
        ...
      ]
    }
  }
}
```

**K线行字段**:
| 索引 | 字段 | 说明 |
|------|------|------|
| 0 | 日期 | YYYY-MM-DD |
| 1 | 开盘价 | |
| 2 | 收盘价 | |
| 3 | 最高价 | |
| 4 | 最低价 | |
| 5 | 成交量 | |
| 6-8 | 其他 | |
| 9 | 成交额 | 港/美股可能在此列（需验证单位） |

**重要发现**: K线响应内嵌 `qt` 节点，包含与独立实时接口完全一致的实时行情数组。
优先使用此内嵌数据，避免额外HTTP请求。

### 2. 实时行情接口（A股备用源）

- **URL**: `http://qt.gtimg.cn/q={code}`
- **编码**: GBK
- **返回格式**: `v_sh600900="1~长江电力~600900~28.24~..."` （~分隔）
- **更新频率**: 交易日内实时更新
- **用途**: A股全字段行情（K线内嵌qt不可用时回退）

**字段映射（~分隔后索引）**:
| 索引 | 字段 | 说明 |
|------|------|------|
| 1 | 股票名称 | |
| 3 | 收盘价/当前价 | |
| 4 | 昨收 | |
| 6 | 成交量（手） | |
| 31 | 涨跌额 | |
| 32 | 涨跌% | |
| 33 | 最高 | |
| 34 | 最低 | |
| 35 | 成交额 | 格式: "万/亿/元"，取第3部分 |
| 38 | 换手率% | |
| 39 | 市盈率（静态） | 实测2026-08-17: qt[39]=18.95=现价27.94/EPS_2025(1.4745)，与东财f164一致；注意 qt[46]=3.28 非PE（量级为PB） |
| 43 | 振幅% | 直采值仅作交叉参考，口径以计算为准（见 field-standards.md 列10） |
| 44 | 流通市值（亿） | |
| 45 | 总市值（亿） | |
| 49 | 量比 | |
| 52 | 市盈率（动态） | 实测2026-08-17: qt[52]=25.30，与东财f162一致 |
| 53 | 市盈率（TTM） | 实测2026-08-17: qt[53]=19.83，与东财f163(×0.01)一致 |

**注意事项**:
- 此接口为 HTTP（非HTTPS），部分环境可能不稳定
- GBK编码，需 `.decode("gbk")`
- 仅A股字段映射可靠，港/美股索引可能不同

## 板块参照数据源

### 东方财富板块行情

- **URL**: `https://push2his.eastmoney.com/api/qt/stock/kline/get?secid={secid}&fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61&klt=101&fqt=0&beg={YYYYMMDD}&end={YYYYMMDD}`
- **编码**: UTF-8
- **返回格式**: JSON
- **更新频率**: 每交易日收盘后
- **用途**: 获取行业板块当日涨跌幅%

**响应结构**:
```json
{
  "data": {
    "klines": ["2026-08-13,开,收,高,低,成交量,成交额,振幅,涨跌幅%,涨跌额,换手率%"]
  }
}
```

**klines 行字段（逗号分隔，fields2=f51..f61 与列一一对应）**:
| 列索引 | f编号 | 字段 |
|------|------|------|
| 0 | f51 | 日期 |
| 1 | f52 | 开盘 |
| 2 | f53 | 收盘 |
| 3 | f54 | 最高 |
| 4 | f55 | 最低 |
| 5 | f56 | 成交量 |
| 6 | f57 | 成交额（元） |
| 7 | f58 | 振幅% |
| 8 | f59 | 涨跌幅% ← 板块参照取此字段 |
| 9 | f60 | 涨跌额 |
| 10 | f61 | 换手率% |

注意：K线 fields2 的 f 编号与实时接口 f 编号是**独立命名空间**（如K线 f58=振幅%，实时 f58=名称），不可混用。

**板块实时行情（备用/交叉）**: `https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields=f43,f57,f58,f60,f170`
- 板块 secid 同样适用（如 90.BK0428）；f170=涨跌幅%（原始值×100，需×0.01还原），2026-08-17盘中实测与K线当日行 col8 一致（时点差属盘中波动）

**常见板块 secid**:
| 板块 | secid |
|------|-------|
| 电力行业 | 90.BK0428 |
| （其他板块需在东方财富行情页面查找） | |

## 备用数据源

当主信源不可用时，可依次尝试以下备用源：

### 新浪财经
- **实时行情**: `http://hq.sinajs.cn/list={code}`
- **历史K线**: `https://finance.sina.com.cn/realstock/company/{code}/hisdata/klc_kl.js`
- **编码**: GBK（实时）/ UTF-8（历史）
- **适用**: A股
- **注意**:
  - 实时行情接口**必须带 `Referer: https://finance.sina.com.cn` 请求头**，否则返回 403
  - 历史K线 `klc_kl.js` 接口为非公开接口，稳定性差（返回格式可能变更或间歇不可用），仅作临时备用，生产上优先用腾讯/东财K线

### 东方财富（个股）
- **实时行情**: `https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields=...`
- **历史K线**: `https://push2his.eastmoney.com/api/qt/stock/kline/get?secid={secid}&...`
- **适用**: A股/港股/美股

### 搜狐财经
- **历史K线**: `https://q.stock.sohu.com/hisHq?code=cn_{code6位}&start={YYYYMMDD}&end={YYYYMMDD}`
- **适用**: A股（沪深统一 `cn_` 前缀，不分 sh/sz）
- **实现状态**: 已实现为 collector 的 `sohu_kline` fetcher（东财历史K线被 WAF 封禁时的历史备胎源）
- **实测确认（2026-08-17, sh600900 / sz000001）**:
  - 返回 JSON 数组（每股一个对象 `{status, hq, code}`），`status=0` 为正常
  - `hq` 行**日期倒序（最新在前）**；start/end 为闭区间
  - 实测无单次天数上限（一次请求可取回 2003 年至今全部 5066 行）

**hq 行字段（JSON 数组）**:
| 索引 | 字段 |
|------|------|
| 0 | 日期 |
| 1 | 开盘 |
| 2 | 收盘 |
| 3 | 涨跌额 |
| 4 | 涨跌幅%（带 `%` 后缀，如 `"-0.50%"`，取值需剥后缀） |
| 5 | 最低 |
| 6 | 最高 |
| 7 | 成交量（手） |
| 8 | 成交金额（万元；换算亿元 ×0.0001，换算元 ×10000） |
| 9 | 换手率%（带 `%` 后缀） |
| 10 | 含义未确认（2024 年后新增列，形如 `"552.00"`；2021 年历史响应无此列）生产字段勿用 |

## 数据源验证策略

### 交叉验证规则
- **至少2源一致**才能确认数据正确
- **3源不一致**时：标记为存疑，询问用户
- **接口超时**不算数据不一致，换源重试

### 验证方法
1. 收盘价：腾讯K线 vs 腾讯实时 vs 新浪/东财
2. 涨跌额/涨跌%：用收盘价和前日收盘价重算验证
3. MACD值：用K线重算与Sheet存储值比对（check_integrity.py 自动执行，属 stock-data-collector skill）
4. 成交额：腾讯实时 `qt[35]` 拆分后与东财K线行第7列（col6，f57）比对（腾讯A股日K无成交额历史列）

## 数据源风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 腾讯接口变更 | 主源不可用 | 配置备用源，脚本有回退逻辑 |
| 实时接口超时 | 当日数据缺失 | K线内嵌qt提供回退 |
| 节假日 | 非交易日无数据 | 脚本自动检测K线最新日期 |
| 除权除息 | 涨跌额/振幅错误 | 配置 expected_div 自动调整 |
| 港/美股字段缺失 | 部分字段空 | 标记待人工补填 |
| 东财 WAF 封禁 | push2/push2his 全域名 Empty reply（2026-08-16 连续封禁，换 UA/Referer 无效；**2026-08-17 实测已恢复**：push2his 个股/板块K线可用，push2 实时间歇性 RemoteDisconnected 需重试或回退 push2delay） | 实时自动回退 push2delay（延时行情）；历史K线封禁期间改用腾讯K线交叉验证 |
